# Global Coal Mine Tracker download

Put the Global Energy Monitor download here, as it comes (zip files or
spreadsheets), with both supplemental files ticked on the form: the mine
ownership chains, and the mine boundaries and potential sources of coal mine
methane. Then run Actions > refresh with `gem_coal` in the box.
