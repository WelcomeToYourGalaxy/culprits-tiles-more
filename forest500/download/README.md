# Forest 500's own data download goes here

Forest 500 gives its data only through the form on
https://forest500.org/forest-500-data-methods/ (financial institution data).
Upload the file it gives you, as it comes (.xlsx or .csv), into this folder.
scripts/soy_money.py reads every file here and colours the map's Forest 500
banks and investors by the financing it gives.

Forest 500 assessment data, Global Canopy, Forest500.org (CC BY-NC 4.0).
