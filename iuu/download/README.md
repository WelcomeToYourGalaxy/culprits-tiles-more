# The Combined IUU Vessel List, downloaded

Trygg Mat Tracking's Combined IUU Vessel List offers a free spreadsheet of every
vessel it lists (currently and formerly IUU listed) at
https://iuu-vessels.org/Home/Download, after asking the reason for downloading.

Put the downloaded .xlsx file in this folder. scripts/iuu_vessels.py then reads
it instead of the website's pages, keeping every column, and the map's
"Fishing vessels blacklisted for illegal fishing" row is drawn from it.

TMT says it welcomes all non-commercial use of the list's data.
